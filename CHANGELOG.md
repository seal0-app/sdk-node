## [0.1.0] - 2026-11-17

First public release.

- The full Seal0 API: entitlement evaluation (one feature or all), features, plans and versions, Customers, subscriptions, overrides and metered usage.
- Typed errors with the API's error code, field and request ID.
- Safe retries, with an idempotency key on every mutation.
- Defaults to `https://api.seal0.app`.
